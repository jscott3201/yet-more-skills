# Adapt to the repository

Read applicable instructions and actual manifests before selecting a specialist or validation command. Preserve existing orchestration and review ownership.

Protocol work needs the correct specification edition and locally authorized source material. Keep allocation-free codecs, transport framing, and language bindings distinct when the architecture requires it.

Storage work must distinguish authoritative data from rebuildable indexes and planned features from implemented contracts. Preserve language semantics, mutation ownership, and unsafe-code policy.

A focused PR gate may intentionally cover less than release qualification. Report the actual scope and follow the current repository's documented gates.

Inspect workspace resolver, edition, compiler floor, excluded packages, and binding support independently; do not infer one from another.

Sources: [Cargo workspaces](https://doc.rust-lang.org/cargo/reference/workspaces.html), [Cargo resolver](https://doc.rust-lang.org/cargo/reference/resolver.html).
