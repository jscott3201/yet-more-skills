# Recording domain language

Prefer the repository's existing formats. When none exists, propose these minimal shapes rather than creating them silently.

## Glossary entry

```markdown
**Canonical term** — One or two sentences defining what the concept is and what distinguishes it.

Avoid: near-synonym used for a different concept; ambiguous legacy name.
```

Include only project-specific concepts. Link a definition to a schema, contract, or decision when that evidence is necessary to keep the meaning stable.

## Decision record

Capture the context, decision, and reason in the smallest durable form the repository accepts. Add options, consequences, status, or supersession only when they help a future maintainer interpret or revisit the decision.

An ADR is not a glossary entry, an implementation plan, or a substitute for owner authorization. Record the chosen tradeoff after it is resolved; do not use the document to manufacture agreement.
